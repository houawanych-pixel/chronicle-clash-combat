# Evertrail — Gameplay Vision

Evertrail is an original top-down action-RPG set within the Chronicle Clash universe. The project is focused on exploration, combat, stealth, world travel, towns, interiors, and memorable locations. These reference images represent the intended direction for the game as development continues.
